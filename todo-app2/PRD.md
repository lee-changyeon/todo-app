## 1. 개요

### 1.1 배경
매일 20개 정도의 할 일을 관리하고 싶지만, 시중의 할 일 앱은 회원가입 · 동기화 · 알림 등 기능이 많아 가볍게 쓰기 어렵습니다.
설치 없이 브라우저에서 바로 열어 쓰는 단순한 개인용 앱이 필요합니다.

### 1.2 목표
1. 브라우저에서 파일을 열기만 하면 바로 쓸 수 있다 (설치 · 로그인 · 서버 없음).
2. 할 일을 추가 · 수정 · 삭제 · 완료 체크할 수 있다.
3. 할 일을 **업무 / 개인 / 공부**로 나누어 볼 수 있다.
4. 오늘 얼마나 끝냈는지 **진행률**로 바로 보인다.
5. 새로고침하거나 브라우저를 다시 열어도 **데이터가 유지**된다.
6. 순수 JavaScript로 **기술적으로 단순하게** 만든다.

### 1.3 범위 밖 (Non-Goals)
- 회원가입 · 로그인 · 여러 기기 동기화
- 서버 · 데이터베이스
- 마감일 · 알림 · 반복 일정
- 프레임워크 · 라이브러리 · 빌드 도구

## 3. 기능 요구사항

우선순위: **P0** = 반드시 필요 · **P1** = 있으면 좋음

### F1. 할 일 추가 (P0)
- 입력창에 내용을 쓰고 카테고리를 고른 뒤 **Enter** 또는 **추가** 버튼으로 추가한다.
- 앞뒤 공백은 제거하고, 빈 값은 추가하지 않는다 (입력창 흔들림으로 알림).
- 최대 100자.
- 추가 후 입력창은 비워지고 포커스가 유지된다.

### F2. 할 일 수정 (P0)
- ✏️ 버튼 또는 텍스트 더블클릭으로 그 자리에서 편집한다.
- 내용과 카테고리를 바꿀 수 있다.
- **Enter** = 저장, **Esc** = 취소, 바깥 클릭 = 저장.
- 빈 값으로 저장하면 원래 내용을 유지한다.

### F3. 할 일 삭제 (P0)
- 🗑 버튼으로 지우며, 확인 창을 띄운다.

### F4. 완료 체크 (P0)
- 체크박스로 완료 / 미완료를 바꾼다.
- 완료 항목은 취소선 · 흐린 색으로 표시하고 목록 아래로 내린다.

### F5. 카테고리 분류 (P0)
- 카테고리: **업무 · 개인 · 공부** (각각 색상 배지).
- 상단 탭 **전체 / 업무 / 개인 / 공부**로 목록을 거른다.
- 마지막으로 선택한 탭을 기억한다.

### F6. 진행률 보기 (P0)
- 전체: `완료 3 / 8 (38%)` 형식 + 프로그레스 바.
- 카테고리별 완료 개수와 비율도 표시한다.
- 체크 · 추가 · 삭제 시 즉시 갱신한다.

### F7. 데이터 저장 (P0)
- 모든 변경을 즉시 `localStorage`에 저장한다.
- 새로고침 · 브라우저 재시작 후에도 목록 · 완료 상태 · 선택 탭이 유지된다.
- 저장 데이터가 깨져 있어도 오류 없이 빈 목록으로 시작한다.

### F8. 부가 기능 (P1)
- 오늘 날짜 표시
- 할 일이 없을 때 안내 문구
- 완료 항목 일괄 삭제 (확인 창 포함)
- 모두 완료하면 🎉 표시

### F9. 키워드 자동 분류 (P1) — v1.1 추가
할 일을 입력하면 내용 속 키워드를 보고 카테고리를 자동으로 골라 준다. 매번 카테고리를 직접 고르는 수고를 줄인다.

- 추가 입력창에 글자를 입력할 때마다 키워드를 검사해, 일치하면 카테고리 선택 상자를 그 카테고리로 바꾼다.
- 자동으로 바뀌었을 때는 입력창 아래에 `🤖 자동 분류: 공부`처럼 알려 준다.
- 키워드 예시 (대소문자 구분 없음, 단어 일부로 들어 있어도 인정 — 예: "보고서를"):

  | 카테고리 | 키워드 예시 |
  |---|---|
  | 업무 | 회의, 미팅, 보고서, 메일, 결재, 기획, 발표, 프로젝트, 고객, 출장, PPT, 엑셀 … |
  | 개인 | 장보기, 마트, 운동, 헬스, 병원, 약속, 청소, 빨래, 은행, 택배, 생일, 여행 … |
  | 공부 | 공부, 과제, 숙제, 시험, 강의, 수업, 복습, 독서, 논문, 알고리즘, 영어, 자격증 … |

- 여러 카테고리 키워드가 함께 있으면 **일치한 키워드가 가장 많은** 카테고리를 고른다. 동점이면 자동으로 바꾸지 않는다.
- 일치하는 키워드가 없으면 사용자가 원래 골라 둔 카테고리로 둔다.
- 사용자가 카테고리를 **직접 고르면** (입력 전이든 입력 중이든) 그 할 일을 추가할 때까지 자동 분류를 멈춘다 (사용자 선택이 항상 우선).
- 할 일을 추가하면 자동 분류가 다시 켜진다.
- 수정(F2) 중에는 자동 분류하지 않는다.
- 서버 · 외부 AI 없이 앱 안의 키워드 목록만으로 동작한다.

## 4. 데이터 모델

### 4.1 Todo 객체
| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | string | 고유 ID |
| `text` | string | 내용 (1~100자) |
| `category` | `"work"` \| `"personal"` \| `"study"` | 카테고리 |
| `completed` | boolean | 완료 여부 |
| `createdAt` | number | 생성 시각 (ms) |

### 4.2 localStorage 키
| 키 | 내용 |
|---|---|
| `todos2` | Todo 배열 (JSON) |
| `todos2Filter` | 마지막 선택 탭 |

> 기존 `todo-app/`과 같은 주소에서 열어도 데이터가 섞이지 않도록 키 이름을 구분한다.

## 7. 수용 기준
| ID | 시나리오 | 기대 결과 |
|---|---|---|
| AC-01 | 텍스트 입력 후 Enter | 선택한 카테고리로 목록 맨 위에 추가 |
| AC-02 | 공백만 입력 후 Enter | 추가 안 됨, 입력창 흔들림 |
| AC-03 | 수정 후 Enter / Esc | Enter는 저장, Esc는 원래 내용 유지 |
| AC-04 | 삭제 → 확인 | 항목 삭제 (취소하면 유지) |
| AC-05 | 체크박스 클릭 | 취소선 · 아래로 이동 · 진행률 즉시 갱신 |
| AC-06 | "업무" 탭 클릭 | 업무 항목만 표시, 새로고침 후에도 탭 유지 |
| AC-07 | 진행률 | 전체 · 카테고리별 개수와 % 정확 |
| AC-08 | 할 일 0개 | 안내 문구 표시 |
| AC-09 | 새로고침 | 항목 · 완료 상태 유지 |
| AC-10 | `localStorage.todos2`에 깨진 JSON 저장 후 새로고침 | 오류 없이 빈 목록 |
| AC-11 | 할 일 20개 이상 | 조작 시 지연 없음 |
| AC-12 | 화면 폭 360px | 레이아웃 깨짐 없음 |
| AC-13 | 브라우저 콘솔 | 오류 없음 |
| AC-14 | "회의 자료 준비" 입력 | 카테고리가 업무로 바뀌고 `🤖 자동 분류: 업무` 표시, Enter로 업무 할 일 추가 |
| AC-15 | "수학 과제" / "헬스장 가기" 입력 | 각각 공부 / 개인으로 자동 선택 |
| AC-16 | 키워드 없는 내용 입력 | 원래 선택한 카테고리 유지, 안내 문구 없음 |
| AC-17 | 카테고리를 직접 고른 뒤 키워드 입력 | 직접 고른 카테고리 유지. 추가 후 다음 입력부터 다시 자동 분류 |
| AC-18 | "회의 끝나고 운동" (업무 1 · 개인 1 동점) | 자동으로 바꾸지 않음 |
