## 작업 규칙
1. 작업 하나를 끝내면 `[ ]`를 `[x]`로 바꾼다.
2. 새 기능은 PRD에 먼저 추가 → TRD에 설계 반영 → 이 문서에 작업 추가 순서로 진행한다.
3. 기능을 추가하거나 고친 뒤에는 TRD 8.2 테스트 케이스를 다시 확인한다.
4. Todo 스키마를 바꿀 때는 기존 `localStorage` 데이터가 깨지지 않도록 새 필드에 기본값을 준다.
