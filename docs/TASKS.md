## 작업 규칙 (세션에서 지킨 방식)
1. 새 기능은 PRD → TRD → TASKS → 구현 → 테스트 순서로 진행한다.
2. 버그는 먼저 테스트로 재현한 뒤 고치고, 수정 후 같은 테스트와 기존 테스트를 다시 돌린다.
3. 같은 문제가 다른 앱에도 있는지 확인하고, 있으면 함께 고친다.
4. push 후에는 배포 주소에서 다시 테스트해 반영을 확인한다.
5. 커밋에는 관련 파일만 넣는다 (PDF · `mypage_artifact.html` · 대화 내보내기 파일 제외).
